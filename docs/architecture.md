# 架构与审查记录

## 独立应用层

- src/main/main.cjs：桌面生命周期、可信窗口检查、IPC、窗口导航与权限限制。
- src/main/service.cjs：API 模块调用、账号凭据、扫码提交与账号切换代次、请求超时、响应密钥字段清理、偏好保存。
- src/shared/contracts.cjs：每个允许操作的严格参数契约，不开放任意方法、cookie、代理、文件路径或解锁参数。
- src/renderer/state.js：统一账号数据、播放状态、队列、歌词、搜索与一起听控制器。
- src/renderer/domain.mjs：曲目 / 歌单 / 节目适配、歌词解析、随机播放袋、邀请链接校验。
- App.vue / Controls.vue / TrackList.vue / Art.vue / Icon.vue：自研界面组件。

无 VutronMusic 代码、插件宿主、多平台音乐库、SQLite 原生绑定或通用本地 HTTP API 服务。

## 状态竞争防护

1. 每次加载音源递增 audioEpoch。旧请求返回时比对代次，避免快切歌后旧音源覆盖新选择。
2. accountEpoch 与主进程 epoch 防止退出 / 切换账号后旧个人数据返回并重新展示。
3. QR key 与账号代次共同校验；只有确认凭据、验证账号后才持久化登录。
4. roomEpoch 防止结束房间后远端加载恢复；roomRevision 防止本地播放指令发出后旧轮询覆盖新操作。
5. 房间写操作串行执行；远端快照应用时不再向服务发回同样的播放指令。
6. 一起听按官方 displayList.result 数据结构解析，同时容忍直接数组形式。
7. 红心只在服务确认成功后更新界面；失败保留原状态。

## 验证策略

核心测试覆盖契约拒绝、凭据清理、持久化权限、QR 竞争、晚返回个人数据、歌词、随机遍历、邀请链接。
桌面测试操作真实 Electron 窗口，使用可控服务验证完整音频播放、UI 状态、账号写入失败、各模式、皮肤、入口、延迟音源和官方房间响应结构。
真实接口测试独立使用匿名网易云服务，记录公开内容读取、搜索、音源与二维码结果。
打包后再次操作桌面窗口，避免仅以源码构建成功证明交付可运行。

## 限制

轮询房间尚未接入网易即时消息推送；需要真实双账号 / 手机互通和长时间同步验收。
音质与可播放状态由网易云和账号权益决定。未在此版本添加下载、MV、第三方音源。

## 0.3.2 窗口与累计统计

桌面歌词由独立 BrowserWindow 与独立 preload 组成，只有查看歌词快照、字号、关闭、拖动和返回主窗口操作；没有音乐 API、账号凭据、网络或文件访问桥。主窗口从现有播放状态发送严格校验、有长度上限的文本快照；歌词窗用 Vue 文本插值显示。旧歌词响应仍受 audioEpoch 约束。主窗口关闭会销毁歌词窗，窗口偏好独立保存，不修改账号偏好文件。

累计一起听使用官方 Android 9.6.05 的 listen/together/relation/statistics/get/v2。请求包含 roomId，可按两位 roomUserIds 查询关系；读取 data.totalConnectionTime，单位为秒。手机播放页的格式化器使用 3600 / 60 换算总小时和分钟。duration 和 currentConnectionTime 不是这里展示的累计数，不作为缺失字段的后备值。统计请求受账号、房间和听友代次校验；进入 / 轮询 / 手动刷新读取官方结果，不做本地增量补数。

协议依据是网易云官方下载的 Android 安装包，仅核对接口、参数、字段与单位；没有复制手机应用代码。测试数据里的千小时数值来自 QA 服务，不能代表真实账号 / 手机对照验收。
